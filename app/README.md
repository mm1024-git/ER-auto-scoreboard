# 점수 집계 프로그램

중계 화면에서 순위표를 생성하여 OBS로 송출한다. 폴더 배치와 배경은 상위 폴더의 README에 정리하였다.

## 실행

```
pip install -r requirements.txt
python main.py
```

동일 폴더에 아래 두 파일이 존재해야 한다.

- `config.json` — 점수 영역의 좌표와 판별 기준
- `digits.npz` — 숫자 인식용 학습 가중치 (`training` 폴더에서 생성)

파이썬 환경 없이 실행할 경우 빌드된 파일(`dist\ER_score\ER_score.exe`; 하단의 제일 마지막 항목 참조)를 사용한다.

## 쓰는 법

`집계 시작` 버튼을 클릭하면 창 선택 화면이 표시되며, 선택된 창에서 값을 읽기
시작한다. 자동집계/수동입력 상관없이, 라운드가 기록될 때는 상단의 라운드 번호를
따른다. 중복된 라운드를 재차 기록하려 시도할 경우 다른 번호를 입력하라는 알림창이
표시된다.

7개 팀이 터미네이트 되면 집계를 정지하고 현재 점수를 기록한다. 다음 라운드가 시작되면
`다음 라운드 시작` 버튼을 눌러서 다시 집계를 시작할 수 있다. 라운드가 비정상적으로
종료되는 등의 상황에서는 `라운드 수동 확정`을 통해 나머지 팀의 등수를 정하여 기록할
수 있다. 집계중인 라운드 기록을 폐기하고 싶을 경우 `현재 라운드 폐기` 버튼을
클릭한다.

점수기록표에서는 이미 기록된 값을 편집할 수 있다. 라운드·팀번호·팀명을 더블클릭할
경우 해당 행의 점수를 초기화할 수 있고, 점수 칸을 더블클릭할 경우 점수를 수정할 수
있다. 한 라운드에 그 어떤 팀의 점수도 기록되어 있지 않으면, 해당 라운드 전체가 표에서
삭제된다. 셀 강조 규칙은 다음과 같다.

- 빈 칸은 회색
- 자동집계 중인 라운드는 노란색
- 등수가 한 라운드 내에서 중복될 경우 빨간색

`오프셋 넣기` 버튼은 각 팀의 점수에 KS/TS를 임의로 더할 수 있다. 경기 도중에 집계를
시작할 경우 이 값을 통해 빠르게 값을 수정할 수 있다. `라운드 추가`는 라운드 정보를
수동으로 기록할 수 있으며, KS/TS/감점을 세부적으로 기록하고 싶을 경우 사용된다.
`새 경기 시작`은 표에 기록된 모든 값을 제거한다.

## OBS 송출 방법

앱 실행 중에는 포트를 하나 열어 스코어보드를 자동으로 송출한다. 포트 번호는 8777부터
8796까지 20개 포트를 순차로 시도해보며, 열린 포트의 주소가 우상단 주소에 자동으로
기입된다. 해당 주소를 복사한 뒤, `OBS - 소스 추가 - 브라우저`를 선택하고, `URL = 해당 주소, 너비 207, 높이 242`로 추가한다.

## 점수 집계 보정

숫자 인식 모델이 낮은 확률로 숫자를 잘못 인식할 가능성이 있다. 혹여 이 상황이 발생할
경우에 대비해, 점수를 규칙 기반으로 수정하는 기능을 포함한다. 테스트케이스를 직접
확인한 것이 아니므로, 보정이 있는 것과 없는 것 중 어느 쪽이 나은지는 장담할 수 없다.
기본값(`시계열 보정`)은 활성화 상태로 설정되어 있다.

※ 계산이 꼬여서 점수갱신이 멈추는 경우가 드물게 발생했다
(정상적인 측정상황은 아니고, 화면을 5~10분씩 계속 넘겨가면서 실험할 때 발견됨).
이와 유사하게, 갱신이 멈추는 버그가 발생할 경우, `현재 라운드 폐기`를 클릭하면
기록을 지우고 현재 화면 기준으로 다시 인식하므로 문제가 해결이 된다.


## 설정

사용환경이나 디렉토리 구성 등에 따라 변경할 값은 `settings.py`에 정리하였고, 집계
기능이 읽어들일 화면의 구성에 관한 값은 `config.json`에 정리하였다.

`config.json`의 `game_area`와 `slots`에 들어가는 값은 각 영역의 좌상단 꼭짓점과 우하단
꼭짓점 좌표이며, 화면 전체를 (0,0)~(1,1)로 표현할 때의 상대값이다.

`configs/config-full.json`은 16:9 전체 화면을 기준으로 지정된 배열이다. 다른 화면에서 사용할 경우, `game_area`를 해당 화면에 맞게 수정한 뒤 동일한 변환(이동 및 축소)을 `slots`의 각 값에 일괄 적용한다. `game_area`만 수정한 뒤 `slots` 변환을 LLM에게 요청하는 방식도 가능하다.

## 실행 파일 만들기

```
.\build.bat
```

해당 명령어를 사용하면 `dist\ER_score\ER_score.exe` 파일이 생성되며, exe 파일과 동일한
폴더에 `config.json`과 `digits.npz`를 위치시키면 위와 동일한 실행 결과를 얻을 수 있다.
사전에 빌드된 실행 파일은 저장소의 Releases에 `ER_score.zip`으로 첨부하였다. 압축을 해제한 뒤 `ER_score.exe`를 실행한다.

※ 빌드 시에 exe와 함께 생성된 `_internal` 폴더 또한 그대로 exe와 동일한 폴더 내에 위치시켜야 한다.
